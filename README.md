# AirWindow AI 

### Smart Air Quality Monitoring & Outdoor Time Planner

AirWindow AI is a web application that helps users identify the best time to go outdoors based on air pollution levels and forecasts.

Users can search for a city to view nearby air-quality measurements, including PM2.5 and PM10, and explore hourly pollution forecasts.

The application analyzes upcoming pollution levels and identifies the least polluted time window across four periods: morning, day, evening and night.

### Built With
Python · Flask · HTML · CSS · OpenAQ API · Open-Meteo API
